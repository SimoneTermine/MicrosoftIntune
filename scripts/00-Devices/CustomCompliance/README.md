# Intune custom compliance scripts

This folder contains discovery scripts and JSON rules for Microsoft Intune custom compliance policies on Windows devices.

## Available examples

- [System drive free space](SystemDriveFreeSpace/README.md) — reports the free space on the Windows system drive and includes a sample compliance rules JSON file.

Review and adjust each policy's thresholds and user-facing messages for your environment. Pilot custom compliance policies before using compliance state in Conditional Access decisions.
