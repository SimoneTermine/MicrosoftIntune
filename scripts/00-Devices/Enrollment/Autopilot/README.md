# Windows Autopilot scripts for Microsoft Intune

This folder contains tools for preparing and validating device data used in Windows Autopilot and Microsoft Intune enrollment workflows.

## Available scripts

- [Test-AutopilotHardwareHashCsv](Test-AutopilotHardwareHashCsv/README.md) — validate a Windows Autopilot hardware hash CSV file before importing it into Intune.

Open the script-specific README for supported CSV formats, prerequisites, examples, and troubleshooting.
