# Collect Windows Update diagnostics for Intune troubleshooting

Use this Windows PowerShell support collector to create a ZIP bundle for Windows Update troubleshooting on Windows 10 and Windows 11 devices. It collects the Windows Update log, recent Windows Update Client, Update Orchestrator, and Delivery Optimization events, update policy registry values, and Windows Update service state.

The bundle can help endpoint administrators investigate scan, download, installation, and update policy issues on Intune-managed Windows devices. The script is read-only: it gathers diagnostics and does not reset Windows Update components or change policy.

## Requirements

- Windows 10 or Windows 11.
- Windows PowerShell 5.1 or PowerShell 7.
- Run in an elevated PowerShell session for the broadest event and ETL log access.
- Available disk space for log conversion and the ZIP file.

## Create a Windows Update support bundle

    .\Export-WindowsUpdateDiagnostics.ps1

Collect events from the last 14 days:

    .\Export-WindowsUpdateDiagnostics.ps1 -Days 14 -MaxEventsPerLog 5000

Choose the ZIP output path:

    .\Export-WindowsUpdateDiagnostics.ps1 -OutputPath C:\Support\WindowsUpdateDiagnostics.zip

The script creates a timestamped ZIP in the current directory by default. Temporary collection files are removed after the archive is created. If Windows Update log conversion or an event log read fails, the bundle includes a note describing the collection issue.

## Included diagnostics

- Windows OS version, build, device name, and last boot time.
- Windows Update service state for Windows Update, BITS, Update Orchestrator, Delivery Optimization, and WaaSMedic.
- Windows Update policy values from common policy and PolicyManager registry locations.
- WindowsUpdate.log generated by Get-WindowsUpdateLog when available.
- Recent events from Windows Update Client, Update Orchestrator, and Delivery Optimization operational logs.

## Privacy and limitations

Windows Update logs and event messages may contain device names, user or tenant details, server names, update URLs, and other environment information. Review the archive before sharing it outside your organization and transfer it using an approved secure channel.

This collector does not determine whether a device is compliant, fix update source configuration, clear caches, reset Windows Update, or guarantee that every diagnostic source is available on every Windows build. Use it as a support bundle alongside Intune and Windows Update for Business reporting.
